# indic-translation-asr-project

Project skeleton for Indic translation & ASR evaluation tasks. Primary dataset: FLoRes-200. This repository contains task folders, data fallback, and evaluation notebooks.

Structure:

- `data/raw/translation_dataset.csv` (fallback)
- `task1_translation_evaluation/` (translation evaluation artifacts)

See `task1_translation_evaluation/README.md` for task-specific notes.
